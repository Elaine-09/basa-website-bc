# 🚀 BASA — Exploring Beyond the Horizon

A multi-page website for the fictional **Belgium Aeronautics and Space Administration**, developed as a **Belgium Campus WPR181 group project** using HTML, CSS and JavaScript.

---

## 🎯 Project Overview

The website introduces BASA, its fictional Aurora Quest mission, company story and team. This version updates the visual layout while retaining the original project material and images.

## 🛠 Tools & Technologies

- HTML5 and semantic page structure
- CSS, Grid, Flexbox and responsive media queries
- JavaScript for image-viewer and demo-form interactions

## ✨ Key Features

- Space-themed homepage with violet accents
- Consistent navigation across the main pages
- Expandable homepage feature descriptions
- Mission and goals sections, company story and team profiles
- Image gallery with working full-image links
- Contact form demonstration; messages are not sent or stored
- Keyboard focus styles, labelled navigation and a skip-to-content link

## 🚀 Getting Started

1. Download and extract this folder.
2. Open **`index.html`** in a modern web browser.
3. Keep the HTML files, stylesheet and `Images` folder together so relative links work.

No installation, build process, database or backend is required. For GitHub, upload the extracted folder contents so `index.html` and `README.md` sit at the repository root.
